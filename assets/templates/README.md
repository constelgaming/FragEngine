# Name templates

This folder holds the `*.PNG` images of **your** in-game name that FragEngine looks for in
the kill feed. They are personal, so they are not part of the repository (see `.gitignore`).

Create them in the app: **Calibrate → Open calibration workspace → Save Template**. Each save
writes a new `CaptureN.PNG` here. Save several (different backgrounds, as killer and as
victim, different team colours) for better detection.

Only files ending in upper-case `.PNG` are loaded.
